# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing
issues before filing new issues to avoid duplicates. For new issues, file your bug or
feature request as a new Issue.

These scripts are provided as **sample code** to automate the ServiceNow configuration steps
documented in [Microsoft Learn](https://learn.microsoft.com/en-us/microsoftsearch/servicenow-knowledge-connector).
They are not part of a Microsoft product or service offering and are not covered by any
Microsoft support agreement or SLA.

For help and questions about using these scripts, please review the documentation in the
[README](README.md) and the referenced Microsoft Learn articles.

For help with the ServiceNow Knowledge Microsoft 365 Copilot connector itself, please use
the standard Microsoft 365 admin support channels.

## Microsoft Support Policy

Support for these scripts is limited to the resources listed above.
